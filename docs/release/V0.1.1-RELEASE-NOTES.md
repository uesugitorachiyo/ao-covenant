# AO Covenant v0.1.1 Release Notes

AO Covenant `v0.1.1` strengthens the policy, approval, evidence, and release
verification contracts used by governed issue repair and the wider AO Stack.

## Included Capabilities

- Enforce bounded authority for governed issue repair, candidate promotion,
  publication, and autonomous-repair evidence.
- Reject stale, mismatched, malformed, duplicate-key, oversized, unsafe-path,
  or over-authority contracts before side effects.
- Preserve digest-bound policy decisions, approval tickets, revocations,
  ledgers, bundles, and cross-repository provenance.
- Harden schema scanning and release packaging against traversal, symlink,
  substitution, and public-safety failures.
- Bind the signed release package to `sbom.go-modules.json`, an exact-source Go
  module inventory carried in the immutable promotion plan.

## Supported Release Artifacts

The protected release workflow publishes signed candidates for:

- Linux x86_64
- macOS x86_64
- Windows x86_64

The release also includes checksums, a signed manifest, the public verification
key, signature and verification reports, provenance, license and notice files,
and the bound Go module SBOM.

## Verification

Verify `SHA256SUMS`, the Covenant release signature, the public provenance
attestations, and the exact platform binary before installation. The promotion
plan must bind the source commit, version, approved manifest, all native
candidate digests, and the SBOM digest.

## Safety Boundaries

AO Covenant evaluates declared authority; it does not create authority. A
passing policy or release verification result does not approve repository
mutation, provider access, deployment, or publication beyond the exact
operator-approved contract.
